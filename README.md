# À mon rythme

Carnet de suivi quotidien de l’activité, de la douleur et de la fatigue.

- Web : ouvrir `index.html` dans un navigateur.
- iPhone : ouvrir `A_Mon_Rythme_iPhone/A_Mon_Rythme.xcodeproj` dans Xcode. L’intégration Apple Santé est décrite dans [le guide d’installation](A_Mon_Rythme_iPhone/INSTALLATION.md).
